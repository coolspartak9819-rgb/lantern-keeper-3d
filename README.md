# Хранитель фонарей 3D

Небольшая атмосферная игра от первого лица о том, как вернуть свет осеннему
парку до наступления ночи.

Собери трёх светлячков, найди погасший фонарь и нажми `E`, чтобы зажечь его.
Тебя ждут восемь фонарей, таймер на 90 секунд, очки и небольшой парк для
прогулки.

## Запуск

```bash
npm install
npm run dev
```

Открой локальный адрес Vite. Нажми **Войти в парк**, используй `WASD` для
движения, `Shift` для бега, мышь для обзора и `E` рядом с фонарём. Если обзор
остановился, кликни по сцене. После окончания раунда клавиша `R` начинает игру
заново. Игра создаёт короткие звуковые сигналы прямо в браузере и не требует
внешних аудиофайлов.

## Технологии

- Three.js and WebGL
- Vite
- Rust -> WebAssembly: детерминированные правила очков и комбо
- C++20: нативный генератор общей палитры для сцены
- Стилизованное PBR-окружение: текстурные материалы земли, тропы и коры
- Кинематографический post-processing: bloom, тонирование, многослойный туман
- Детализированные фонари со стеклом, металлом, нитью накаливания и динамическим светом
- Динамические тени, светлячки, горные силуэты и адаптивный HUD
