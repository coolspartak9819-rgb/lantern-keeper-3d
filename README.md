# Хранитель фонарей 3D

Динамичная 2.5D/стилизованная 3D игра от первого лица: нужно провести
путников через осенний лес и защитить их от теней.

Путники идут к дому по тропе, а из леса выходят волны теневых волков,
громил и мотыльков. Игрок собирает светлячков и заряжает восемь фонарей,
которые защищают караван, пока не закончится заряд.

## Игровой цикл

- Путники восстанавливают здоровье в зоне работающих фонарей и теряют его в темноте.
- Жёлтый светлячок наносит урон теням в радиусе фонаря.
- Синий расширяет световую зону и замедляет монстров.
- Фиолетовый раз в три секунды выпускает импульс по площади.
- `Пробел` активирует «Вспышку»: тратит два светлячка и отбрасывает тени рядом с игроком. Перезарядка 10 секунд.
- Победа наступает, когда все шесть путников доходят до дома. Поражение наступает, когда весь караван потерян или заканчивается время.

## Запуск

```bash
npm install
npm run dev
```

Открой локальный адрес Vite. Нажми **Войти в парк**, используй `WASD` или
стрелки для движения, `Shift` для рывка, мышь для обзора, `1`/`2`/`3` для выбора
светлячка, `E` рядом с фонарём для зарядки и `Пробел` для вспышки. Если обзор
остановился, кликни по сцене. После окончания раунда клавиша `R` начинает игру
заново.

## Технологии

- Three.js and WebGL
- Vite
- Rust -> WebAssembly: детерминированные правила очков и комбо
- C++20: нативный генератор общей палитры для сцены
- Стилизованное PBR-окружение: текстурные материалы земли, тропы и коры
- Кинематографический post-processing: bloom, тонирование, многослойный туман
- Детализированные фонари со стеклом, металлом, нитью накаливания и динамическим светом
- Динамические тени, светлячки, горные силуэты и адаптивный HUD
